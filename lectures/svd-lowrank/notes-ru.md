## Что ты должен уметь объяснить без слайдов (проверь себя)

1. Что такое сингулярные числа — **одной фразой**: «полуоси эллипсоида, в который матрица превращает единичную сферу».
2. Почему `σᵢ = √λᵢ(AᵀA)` и почему σ всегда ≥ 0.
3. Что утверждает теорема Эккарта–Янга: **обрезанное SVD — лучшая матрица ранга r**, ошибка равна корню из суммы квадратов отброшенных σ.
4. Когда сжатие вообще возможно: `r·(m+n) < m·n`.
5. Почему σ и λ — разные вещи (пример `[0 1; 0 0]`).
6. Главный вывод лекции: **сжать готовую матрицу ≠ обучать в низкоранговом семействе**.

Если какой-то пункт не объясняешь — не иди дальше по слайдам, это единственные шесть вещей, которые слушатель унесёт.

## Что писать на доске (5 минут подготовки до лекции)

```
1. окружность → эллипс, подписать σ1, σ2
2. A = [1 2; 2 4]:  σ1² + σ2² = 1+4+4+16 = 25 → σ1 = 5, σ2 = 0
3. r(m+n) < mn
4. ‖A − A_r‖ = √(σ²_{r+1} + σ²_{r+2} + …)
5. B = [0 1; 0 0]: λ = 0,0   σ = 1,0
```

Доска идёт **слева направо**, ничего не стирай до конца: к слайду 13 ты вернёшься к пункту 4.

## Пять вопросов, которые зададут (и короткие ответы)

**«А зачем это вообще нужно?»**
Сжатие моделей и картинок: та же матрица, меньше чисел. И диагностика: спектр показывает, сколько в матрице «настоящих» направлений.

**«Почему нельзя просто выкинуть маленькие числа из матрицы?»**
Потому что «маленькое» зависит от базиса. SVD выбирает оси так, что выкидывать можно осмысленно, и даёт лучший результат из всех возможных.

**«σ всегда меньше λ?»**
Нет. Пример: `[0 1; 0 0]` — λ = 0, а σ = 1. Для симметричных σ = |λ|.

**«А если матрица не квадратная?»**
Сингулярные числа определены для любой. Собственные — только для квадратных.

**«Почему у обученной сети спектр не обрывается?»**
Потому что обучение не обязано давать низкоранговую матрицу: градиентный спуск ищет любую матрицу, которая уменьшает ошибку. Отсюда главный вывод лекции.
