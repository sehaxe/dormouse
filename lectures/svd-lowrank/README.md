# Лекция по линалу: «Зачем матрицу можно заменить двумя тонкими»

Одна теорема (Эккарт–Янг), один опыт на экране и один результат, который противоречит
ожиданию — всё измерено на настоящей нейросети на 102 678 943 параметра.

## Что здесь лежит

| файл | что это |
|---|---|
| `slides/ru.html` | **русская колода, 14 слайдов** — основной вариант для БГУИР (первый курс) |
| `slides-ru.pdf` | та же колода в PDF (1280×720, для показа и печати) |
| `slides/index.html`, `slides.pdf` | английская версия, 10 слайдов |
| `notes-ru.md` | конспект выступающего: тайминг по минутам, что писать на доске, три момента, где публика включается, пять вопросов с ответами, что прочитать за час |
| `handout-ru.html`, `handout-ru.pdf` | раздатка на 2 страницы: определения, разобранный пример, теорема, 4 задачи с ответами |
| `src/lecture_svd.py` | считает спектры реальных матриц модели → `numbers.json` + рисунки |
| `src/demo_svd_image.py` | опыт с картинкой: rank 1/5/20/50, ошибка, число чисел |
| `numbers.json` | все числа, которые цитируются на слайдах (для проверки) |
| `figures/` | рисунки: спектры, масса, лестница рангов, демо с картинкой |


## Честность чисел

- спектры и «масса при ранге r» — из `checkpoints/flagship/flagship.pt` (102 678 943 параметра, 4.2 ГБ текста);
- лестница рангов (+0.027 / +0.136 бит на байт) — из A/B проекта, три сида на плечо;
- демо с картинкой — SVD 480×480, ошибка совпадает с формулой теоремы до третьего знака
  (это и есть проверка, что теорема не «примерно»).

Ни одно число на слайдах не введено руками: всё считается скриптами в `src/`.
