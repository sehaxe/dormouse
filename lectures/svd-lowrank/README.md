Одна теорема (Эккарт–Янг), один опыт на экране и один результат, который противоречит
ожиданию — всё измерено на настоящей нейросети на 102 678 943 параметра.

## Как показывать

```bash
xdg-open slides/ru.html
# ←/→ листать · t — тема (светлая / тёмная / экранная) · p — печать · клик — дальше
# тема запоминается; можно сразу задать ссылкой:  ru.html?theme=dark
```

Слайды **не содержат вопросов к аудитории**: вопросы задаются голосом, они выписаны
в `notes-ru.md` с точным текстом и местом. На слайде — только то, что нужно глазам:
заголовок, одна мысль, формула, картинка.

## Честность чисел

- спектры и «масса при ранге r» — чекпоинт `checkpoints/flagship/flagship.pt` (102 678 943 параметра, 4.2 ГБ текста);
- лестница рангов (+0.027 / +0.136 бит на байт) — A/B проекта, три сида на плечо;
- демо с картинкой — SVD 480×480; ошибка совпадает с формулой теоремы до третьего знака.

Ни одно число на слайдах не введено руками: всё считается скриптами в `src/`.

## Почему не Typst

Пробовал: Typst даёт лучшую математику, но здесь важнее готовый экранный формат —
1280×720, переключение темы под проектор, клавиатурная навигация, мгновенная правка.
Порт стоил дороже пользы, поэтому колода живёт в HTML, а математика набрана моноширинным
(на проекторе читается лучше серифного). Для раздатки это не важно — она в PDF.
