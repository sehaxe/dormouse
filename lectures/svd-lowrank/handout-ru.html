Сингулярные числа и теорема Эккарта–Янга

1. Что такое сингулярные числа

Матрица A размера m × n — это линейное отображение. Единичная сфера под её действием превращается в эллипсоид; полуоси этого эллипсоида — сингулярные числа σ₁ ≥ σ₂ ≥ ⋯ ≥ 0.

σi = √λi(AᵀA) отсюда: σ всегда вещественные и ≥ 0; определены для любой матрицы

Ранг = число ненулевых σ. Сумма квадратов всех элементов A равна σ₁² + σ₂² + ⋯ (потому что это след AᵀA).

2. Разложение

A = U Σ Vᵀ Vᵀ поворачивает вход на главные оси, Σ растягивает, U поворачивает в выход

3. Теорема (Эккарт–Янг, 1936)

Пусть Ar = σ₁u₁v₁ᵀ + ⋯ + σrurvrᵀ — обрезка до r слагаемых. Тогда для любой матрицы B ранга не больше r:

‖A − Ar‖ ≤ ‖A − B‖,    ‖A − Ar‖ = √(σr+1² + σr+2² + ⋯)

‖·‖ — евклидова длина матрицы: корень из суммы квадратов всех элементов («норма Фробениуса»). Смысл: обрезка SVD — лучшая матрица ранга r, и ошибка известна заранее.

4. Почему это верно (идея)

Любая матрица B ранга r обнуляет подпространство размерности не меньше n − r (своё ядро). Возьмём единичный вектор z из ядра: Bz = 0. Тогда

‖A − B‖ ≥ ‖(A − B)z‖ = ‖Az‖

и остаётся выбрать направление, которое B не видит, а A видит сильнее всего — это σr+1.

5. Разобранный пример

A = [1 2; 2 4]. Вторая строка = 2 × первая, значит ранг 1, одно σ равно нулю.

Сумма квадратов элементов: 1 + 4 + 4 + 16 = 25 = σ₁² → σ₁ = 5, σ₂ = 0.

Разложение: A = σ₁ u vᵀ, где u и v — единичные векторы вдоль (1, 2).

Задачи (с ответами)

Задача 1 · посчитать руками

A = [2 0; 0 1]. Найдите σ, постройте A₁ (обрезку до ранга 1), посчитайте ошибку по формуле и проверьте прямым вычислением.

Ответ. AᵀA = [4 0; 0 1], λ = 4 и 1 → σ = 2 и 1. A₁ = [2 0; 0 0]. Ошибка по формуле √(σ₂²) = 1; прямым вычислением ‖A − A₁‖ = ‖[0 0; 0 1]‖ = 1. Совпало.

Задача 2 · проверить тождество

Для A = [1 2; 2 4] проверьте, что сумма квадратов элементов равна σ₁² + σ₂².

Ответ. 1 + 4 + 4 + 16 = 25; σ₁² + σ₂² = 25 + 0 = 25.

Задача 3 · когда сжатие вообще есть

Матрица 1000 × 1000 имеет ранг 10. Сколько чисел нужно, чтобы хранить её точно в низкоранговом виде, и во сколько раз это меньше?

Ответ. 10 · (1000 + 1000) = 20 000 против 1 000 000 → в 50 раз меньше, без потерь.

Задача 4 · σ ≠ λ

Для B = [0 1; 0 0] найдите собственные и сингулярные числа. Объясните разницу одной фразой.

Ответ. λ = 0 и 0; σ = 1 и 0. Собственные числа описывают повторное применение (B² = 0), сингулярные — растяжение за один шаг: вектор (0, 1) переходит в вектор длины 1.

Что унести с лекции

  • Матрица — это форма; σ — её полуоси; ранг — число ненулевых полуосей.
  • Обрезка SVD оптимальна, а ошибка равна √(сумма квадратов отброшенных σ).
  • У обученных нейросетей спектр не обрывается: ранг 64 из 1024 держит всего 28–45% энергии.
  • Сжать готовую матрицу и обучать сразу в низкоранговом семействе — разные задачи; теорема говорит только про первую.
