# Lectures

Teaching material built from this project's own measurements.

| folder | what |
|---|---|
| `svd-lowrank/` | Линал, первый курс: «Зачем матрицу можно заменить двумя тонкими» — теорема Эккарта–Янга, опыт на странице текста, спектры настоящей сети |

Каждая папка самодостаточна: PDF-колода (светлая и тёмная тема для проектора), конспект
выступающего, раздатка и скрипты, которые пересчитывают все числа на слайдах.
