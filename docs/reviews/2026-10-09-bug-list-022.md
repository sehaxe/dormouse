**2026-10-09.** One row per defect, each with its measurement, its owner, and
the workaround's *measured* effect. Evidence levels are named, because the
difference between "proven" and "correlated" is what decides where the fix
goes — and half of today's work was refuting my own leading hypotheses.

## D. Workarounds, measured — none of them is a fix

| workaround | effect | verdict |
|---|---|---|
| `--engram-ram` (host-RAM tables, CPU updates) | worst ce 234 / 2.2e5 / 2.3e8 over 3 runs | **does not help** |
| `persistent_memory = "disabled"` | 10/10 → 1/3–3/3 explosions, **zero** step-time cost (198–207 ms/step, identical `ce`, measured on `--no-kda`) | moves the coin; not shipped, because shipping it would hide the defect (ADR-0011) |
| `--opt adamw` / `--no-kda` / `--no-engram` / `n_experts=1` | clean in 1 run each | dodge, not a fix |
| `dormouse-pre4` stack | the only measured-trustworthy numbers | use it for any A/B that has to be believed |

## E. What burn needs to fix for us, in order

1. **A1** — reproducibility of the candidate choice (pin, or a verified winner). This is the blocker: without it, 0.22 cannot produce a number a reader can trust.
2. **A2** — the persistent cache, which is the natural home for A1's fix and does not run today.
3. **A4** — a statement on which bf16 path 0.22 took, so our tripwire and AGENTS §2.1 can stop lying in one direction or the other.
4. **A5** — nothing, until our reference step is better than its own noise; then re-ask.
5. **A3** — hygiene, whenever.
