# 2026-11-04 — ПОДТВЕРЖДЕНО: 9 из 512 экспертов работают, контроллер ушёл в разнос

## Поправка к первому замеру

Первый прогон `scripts/route_hist.py` читал `state["model"]` и **не применял
секцию `moe`** — то есть мерил роутер БЕЗ обученного `lfb_bias`. Отсюда «80 из
512». Правильный замер (`load_model_state`, т.е. тот же загрузчик, что у
eval/resume; чекпоинт `checkpoints/m400/m400.pt`, шаг 149 999, реальные байты
`fwedu.bin`, b4×s1024, 8 192 назначения):

```
сохранённый lfb_bias:   min -218.27  max +72.67  mean +34.30
роутер без bias:        живых  80/512 (15.6%)  max 678   top10  50.1%
роутер + СОХРАНЁННЫЙ bias: живых   9/512 ( 1.8%)  max 4096  top10 100.0%
```

То есть контроллер не «не помог» — он **сломал роутинг**: один эксперт держит
4096 из 8192 назначений (ровно те 12 ГиБ банка, что мы видели), девять несут
весь трафик, остальные 503 не получают ни токена, ни градиента.

## Механизм

`experts.py::_lfb_step`, режим `sign`:

```
b_e -= coef · sign(L_e − mean L)        L_e — КУМУЛЯТИВНЫЕ счётчики
```

1. **Нет равновесия.** Знаковый шаг по кумулятивным счётчикам — интегратор с
   насыщением: у вектора нет точки покоя, он дрейфует, пока порядок не
   замрёт. За 150k шагов `mean` дошёл до `+34`, разброс — до 294 логит-единиц.
2. **Нет границы.** `b` не клипается: ±200 в логитном пространстве навсегда
   перебивает собственные скоры роутера (±5), и top-k читает уже не роутер, а
   историю счётчиков. Порядок замерзает — 9 живых.
3. **Paper (2408.15664) мерил другое:** γ=0.001 и per-batch max-violation;
   наш A/B 2026-10-15, на который ссылался докстринг, шёл при `capacity>0` с
   дропами — другой режим. Кумулятивная форма не была проверена в dropless.

## Что сделано (все армы за флагами, дефолт — старый `sign`)

| флаг | смысл |
|---|---|
| `moe_lb_mode="prop"` | `b -= gamma·(L_e−mean)/max(1,mean L)` по СЧЁТЧИКАМ ТЕКУЩЕГО ОКНА, `b` клипается в ±`moe_lb_clamp` |
| `moe_lb_gamma=0.001` | шаг P-регулятора (paper's γ) |
| `moe_lb_clamp=2.0` | бюджет в логитных единицах; `±2` — уже треть скоров роутера |
| `moe_lb_mode="aux"` | без bias-контроллера; Switch/GShard `coef·E·Σ f·P` в лосс, градиент только в роутер |
| `moe_routing_health=true` | счётчики `moe_route_live` / `_max_x1000` / `_top10_x1000` / `_ent_x1000` / `_n`, device-суммы за окно, дрейн на лог-каденции |
| resume | `max|bias| > 10` ⇒ LOUD с `Escape:` (тренировочный resume); ридер печатает ту же строку и отдаёт файл как есть; здоровый диапазон печатается одной строкой на каждом resume |

`sign` не тронут ни на бит: он остаётся legacy-армом, на котором снят замер.

## Гейт на баг

`tests/test_moe_balance.py::test_the_sign_arm_winds_past_the_clamp_and_prop_does_not`:
3 000 шагов ЗАСКРИПТОВАННОГО перекошенного роутинга (эксперты 0/1 забирают всё):

* `sign` (`coef=0.05`): `max|b| = 150` — тот же порядок, что `[-218, +72]` в
  файле; шаг за шагом растёт дальше (замер: 150 → 152 за два шага);
* `prop` (`gamma=0.001`, clamp 2.0): `max|b| = 2.0` ровно, ни на одном шаге не
  выходит за клип, и после снятия скрипта живой банк восстанавливается
  (15/16 экспертов за 40 шагов).
