## Каждое решение — с вердиктом на руках

| выбор | замер |
|---|---|
| плотная вместо банка | 600 шагов, 3 сида, равный активный MAC: dense −0.067 BPB |
| f=4096, d=1536 | f=6144 → 2.3526 против 2.3531 (ничья); d=1920 → 2.5435 (хуже) |
| engram 128k | 12.6M…201M таблицы все в пределах 0.016 BPB; берём дешёвую |
| MSA off | ничья при 2k и 3.5× медленнее; 7.6M мёртвых параметров убраны из пресетов |
| muon_state bf16 | +18% шага (замерено ранее), 489 МиБ памяти |

## Что НЕ вошло и почему

```
TSCT-2 (basis/lr/revive)   смёржено (9b5e6dd), но на плотной модели неприменимо
tsct_packed (521→5 запусков)  мердж отложен: конфликт в optim.py, а банк мы не тренируем.
                              Ветка сохранена, вернёмся если банк вернётся в рецепт.
CSA/LayerRoPE              при 1 КБ измерены как ничьи; удалять после A/B по скорости
```

## Контрольная точка (обязательно)

```

если впереди или наравне — продолжаем до 200k
```
