# The technology battery — verdicts, windows, and what was NOT run

**Date** 2026-10-20 → 2026-10-21 · **lane** Python port (`port/`) · **card** RTX 5060 Ti 16 GB
**Rule applied** AGENTS §1.2: a mechanism beats its own removal on held-out BPB at a
fixed step budget, 3 seeds per arm, and a win must beat the control's own spread.
A tie deletes the mechanism (or keeps it only if a driver names a different,
scheduled regime).

Every row below carries its eval window. **A BPB is only comparable within one
window** (AGENTS §2.6): `eval_batches × batch × seq_len` bytes.

  incompatible** (the channel consumes byte positions).
