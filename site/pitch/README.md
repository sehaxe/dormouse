# Питч — «Плотность»

10 слайдов, 5–7 минут. Один файл, без зависимостей.

## Смотреть / показывать

Открыть `index.html` в браузере и нажать F11 (полный экран).

| клавиша | действие |
|---|---|
| → / ↓ / пробел | следующий слайд |
| ← / ↑ | предыдущий |
| Home / End | первый / последний |
| **T** | тёмная сцена ⇄ тёплая бумага |

Клик правой трети экрана — вперёд, левой — назад (для пульта-презентера,
который шлёт только клики).

## PDF

- `dormouse-pitch-stage.pdf` — тёмная сцена (для проектора в тёмной комнате)
- `dormouse-pitch-paper.pdf` — тёплая бумага (для рассылки и печати)

Пересобрать после правок:

```bash
chromium --headless --no-pdf-header-footer --print-to-pdf=dormouse-pitch-stage.pdf \
  "file://$PWD/index.html"
sed '0,/data-theme="stage"/s//data-theme="paper"/' index.html > /tmp/p.html
chromium --headless --no-pdf-header-footer --print-to-pdf=dormouse-pitch-paper.pdf \
  "file:///tmp/p.html"
```
